# T-1.5.2 Read Omnipod DASH history

[← US-1.5](../README.md) · [Epic E1](../../../README.md)

**As a** user, **I want** MFS to read pod reservoir, status and dose history **so that** it can show them with meals.

**Acceptance:** Read-only, except pod activation (pair, prime, insert cannula) from Connect devices, which runs only through OmnipodKit's setup screens and is accepted by the owner (see the README, Omnipod pairing). No bolus, temp basal, suspend or resume command is ever called. Contracts are described in the task below.

## Subtasks

### ST-1.5.2.1 Implement a read-only PumpManagerDelegate

**Status:** Planned. `OmnipodKit` is linked and builds in CI.

Contract of `OmniPumpManager` (plugin identifier `Omni`), from the pinned source:

**Inputs MFS provides**
- `pumpManagerDelegate`, `delegateQueue`, persisted `rawState`, `RileyLinkDeviceProvider`.

**Outputs MFS receives** (delegate callbacks)
- `pumpManager(didUpdate status)`: basal and bolus state, insulin type, uncertainty flag.
- `pumpManager(didReadReservoirValue)`: reservoir units and date.
- `pumpManager(hasNewPumpEvents)`: bolus, temp basal, suspend and resume history.
- `pumpManagerDidUpdateState`: persist `rawState` now.
- `issueAlert` / `retractAlert`: pod alerts (low reservoir, expiring, suspend ended, and others).

**Readable state:** `status`, `lastSync`, `isOnboarded`, `inSignalLoss`, `state.podState` (expiry, activation, last insulin measurements).

**Errors:** `noPodPaired`, `insulinTypeNotConfigured`, `notReadyForCannulaInsertion`, `invalidSetting`, `podTypeNotConfigured`, `communication`, `state`.

**Constraint:** a pod pairs to one controller, so MFS cannot read a pod that Loop or iAPS already controls.


### ST-1.5.2.2 Safety review: no delivery commands

**Status:** Planned

`OmniPumpManager` exposes insulin-delivery commands: `enactBolus`, `enactTempBasal`, `cancelBolus`, `suspendDelivery`, `resumeDelivery`, `syncBasalRateSchedule`, `syncDeliveryLimits`.

- **Rule:** MFS must not call any of them.
- **Check:** a test or lint step that fails if these symbols appear in `Sources/`, plus a human review before any release that links `OmnipodKit`.
