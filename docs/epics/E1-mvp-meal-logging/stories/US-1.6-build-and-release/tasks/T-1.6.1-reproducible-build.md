### ST-1.6.1.3 Apply selected updates

- **Where:** manual `Update Dependencies` workflow.
- **Behavior:** select any submodules and/or fastlane. The workflow updates them to their upstream default-branch commits or latest fastlane release, commits the changes, and runs the existing simulator tests before fast-forwarding the default branch. Swift package updates are not supported by this workflow.
- **Review gate:** before installing or testing updates, a heuristic scan compares added source lines in selected submodules and the direct fastlane gem. New network, sensitive-device/data, process-execution or encoded-content patterns, changed binary files, and nested submodule changes stop the update for manual review; findings appear in the job summary. False positives are possible. The scan does not inspect fastlane's transitive gems, all file types, or prove an update safe. Review and apply flagged updates manually.
- **Requirements:** Actions must have permission to push to the default branch. Branch protection still applies. If the branch moves during testing, the push fails; rerun the workflow rather than force-pushing.
- **CI:** the push uses `GITHUB_TOKEN`, so it does not trigger other push workflows. The simulator tests run before the push.
