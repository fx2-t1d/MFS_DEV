# MFS documentation

Work is organized as **Epic → User story → Task → Subtask**. There is one epic; its MVP is US-1.1 and every other story supports it. Each level links to its children and back to its parent.

| Epic | Status |
| --- | --- |
| [E1 MVP: low-effort meal logging](epics/E1-mvp-meal-logging/README.md) | In progress |

Status reflects the repository at the time of writing; see the [project README](../README.md) for behavior details.

Units and notation (c for carbohydrate grams, p for protein grams, mg/dl for glucose, units or u for insulin) are defined in the [project README](../README.md#units-and-notation).
